# 1.31.12

Released on 2026-10-30.

## Fixed

- Commas in frontmatter no longer break titles and descriptions. Only `tags` and `import` are split
  into lists, so `title: Toast, grind, store` now stays exactly as written in the page title, meta
  description and archive cards. Project settings follow the same rule: only `ignore`, `script`,
  `scriptModule` and `copyFiles` are split.
- Archive card excerpts use the page `description` when it is set. Otherwise they use the first
  paragraph, including paragraphs that wrap over several lines, as plain text.
- Partials (files starting with `-`) no longer show up as broken cards on article and blog archives.
  They still make up the content of `sections` archives.

## Changed

- Article archive cards and "More Pages" cards show the page `image` (or `thumbnail`) when there is
  one, instead of only an icon.
