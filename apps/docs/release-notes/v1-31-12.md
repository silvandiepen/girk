# 1.31.12

Released on 2026-09-22.

## Changed

- `sharp` now tracks 0.35 instead of 0.31. It ships prebuilt platform binaries, so
  installing Girk no longer pulls the unmaintained `prebuild-install` downloader or
  compiles anything locally.

## Removed

- The unused `express` and `mv` dependencies. Neither was imported anywhere; `mv` was
  the last thing dragging `rimraf@2`, `glob@6` and `inflight` into the tree.
- `rimraf` moved to `devDependencies`, where the `build:full` script that uses it lives.
